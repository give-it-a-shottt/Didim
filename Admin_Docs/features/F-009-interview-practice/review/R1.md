- [신규] [제안] [추정] `interview_evaluation._saved_by_text`가 질문 글을 키로 dict를 만들어, AI가 같은 질문 글을 두 번 내면 하나로 합쳐 센다(저장은 둘일 수 있고 `summary.saved`는 하나로 줄어듦). 심은 질문은 `len({question}) == len(items)` 테스트로 막혀 있으나 AI 질문 경로(`evaluate_card`)는 막는 곳이 안 보임. 확인하면 [확실]: `save_interview`가 같은 질문 글을 중복 저장하는지(interview_service.py) — 고치는 방법: 키를 `view.id`로 하거나 중복이면 `received`와 `saved`가 어긋나는 것을 결과에 표시.
