# 웹 접근성 스터디 기록

## 상품 상세 화면 접근성 개선
스터디에서 각자 맡은 화면을 접근성 기준으로 점검했다. 내가 맡은 상품 상세 화면은 Lighthouse 접근성 점수가 58점이었고, 키보드만으로는 옵션 선택 버튼에 들어갈 수 없었다.

div로 만든 옵션 버튼을 button 요소로 바꾸고, 상품 이미지에 대체 텍스트를 넣고, 수량 입력 칸에 label을 연결했다. 스크린리더(NVDA)로 화면을 처음부터 끝까지 읽어 보며 읽는 순서가 어색한 곳을 고쳤다.

접근성 점수가 58점에서 96점이 됐고, 키보드만으로 옵션 선택부터 장바구니 담기까지 할 수 있게 됐다.

## 모바일 레이아웃 정리
같은 화면을 폭 360px 휴대폰에서 열면 가격과 버튼이 겹치고 가로 스크롤이 생겼다.

고정 너비로 잡혀 있던 영역을 flex와 미디어 쿼리로 바꾸고, 좁은 화면에서는 구매 버튼을 화면 아래에 붙이는 배치로 나눴다.
