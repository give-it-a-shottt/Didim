## 체크 항목별 근거
- 새 칸 다섯 곳 일치 → api-list(metrics[].display 문자열, runs[].data_items [{key,label,count}]) · 백엔드(MetricOut.display: str, DataItemOut, RunOut.data_items) · 화면 타입(ReportMetric.display, ReportDataItem, ReportRun.data_items) · 화면 검사(display 문자열, data item key · label 문자열 · count 숫자) · 가짜 백엔드(metric(...display), data_items, BAD_METRIC_RUN) 이름 · 타입 · 위치가 같음. 가짜 백엔드의 display는 JS로 따로 만든 글자라 서버 규칙을 검증하진 않지만(규칙은 pytest) 계약 모양은 맞음 → 일치.
- 하위 호환 → 기존 칸(data, metrics의 key · label · kind · value, evals, 회차 메타) 모두 남음, 테스트가 data 그대로인지 단언. 화면에서 지운 것은 내부 함수라 API가 아님 → 문제없음.
- 에러 형식 → 모양이 틀린 회차는 API가 건너뛰고 화면은 전체 '못 읽음'(D-030), 테스트 · e2e가 받침 → 일치.
