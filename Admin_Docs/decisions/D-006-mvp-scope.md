## 개발자 상세

### 넣는 것
- 기록 추가(마크다운 → 노션), 기록 검색, 퀴즈 복습 + 오답노트, 경험 카드(만들기 · 빈칸 채우기 · 근거), 공고 분석, 근거 달린 자소서, 면접 연습(질문 생성 + 근거 + 내 답 메모), 첫 방문 홈 + 샘플 체험, 평가 리포트, 랜딩
- 면접 질문은 경험 카드에서만 생성하고, 면접 연습 탭은 그 공고에 매칭된 카드의 질문을 모아 보여 준다(중복 제거).

### 2차로 미루는 것
- Cmd+K 전역 검색, 지원 칸반(드래그) → MVP는 D-day 순 목록
- 카드를 문장으로 드래그해 근거 붙이기 → MVP는 [카드 연결] 버튼 + 카드 검색 팝오버
- 근거를 문장 높이에 맞춰 정렬하기
- 면접 음성 녹음 · AI 채점, PDF 가져오기, 깃허브 기록 가져오기

| 후보 | 장점 | 단점 |
|---|---|---|
| ① 객관식만 | 채점 확실, 3주차가 가벼움 | 단조로움 |
