# D-002 공고는 붙여넣기로 받고, 사이트를 긁어 오지 않는다

## 한눈에 보기 (코드 몰라도 OK)
상태: [통과] 사용자가 골랐어요(2026-11-05).
무엇을: 사용자가 공고 URL이나 본문을 직접 붙여 넣어요. 서비스가 채용 사이트를 자동으로 긁어 오지(크롤링) 않아요. 나중에는 사람인 채용정보 API(이용 신청 · 승인 필요)로 넓혀요.
왜: 자동으로 긁어 오면 사이트 약관 문제가 생길 수 있어요.

## 개발자 상세

### 결정
- URL은 사용자가 준 것만 읽는다. 읽기에 실패하거나 로그인이 필요한 공고면 "본문을 붙여 넣어 주세요" 안내.
- 사람인 API는 5주차 전후에 신청한다. 승인 전까지는 붙여넣기만.
- 평가용 공고는 사람이 고른 실제 공고 대신 가상 공고를 쓴다(D-005).

### 이 결정을 바꿔야 하는 조건
- 사람인 API 승인이 나면 "공고 검색 → 가져오기"를 추가한다.
