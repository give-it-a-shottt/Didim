[가상] 티켓온 · 백엔드 개발자 (신입)

티켓온은 공연 · 전시 예매 플랫폼입니다. 인기 공연 예매가 열리는 순간에도 느려지지 않는 서버를 함께 만들 백엔드 개발자를 찾습니다.

주요 업무
- 예매 · 좌석 · 알림 API 개발
- 예매 오픈 시간대 성능 개선

자격 요건
- 느린 작업을 비동기로 분리해 응답 시간을 줄여 본 경험
- 동시성 문제를 찾아 해결해 본 경험
- Docker로 서비스를 배포해 본 경험
- WebSocket으로 실시간 기능을 만들어 본 경험

우대 사항
- Go 언어로 개발해 본 경험

복지
- 공연 관람비 지원, 생일 반차
