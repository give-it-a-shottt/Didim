# D-026 글꼴은 Pretendard 하나만 쓴다 (명조 없앰)

## 한눈에 보기 (코드 몰라도 OK)
상태: [통과] 사용자가 골랐어요(2026-11-16).
무엇을: 화면의 모든 글을 Pretendard 하나로 써요. 내 기록 원문 인용에 쓰던 명조(Noto Serif KR)를 없애요. 인용은 글꼴 대신 왼쪽 줄 · 낫표(「 」) · 출처 줄로 "내 기록에서 온 글"임을 보여 줘요.
왜: 사용자가 "폰트는 모두 프리텐다드로"라고 정했어요(2026-11-16).

## 개발자 상세
### 상황
- 지금까지는 두 글꼴을 썼다: 화면 · AI = Pretendard, 내 기록 원문(인용 · 노트 원문) = Noto Serif KR(설계 원칙 7 "명조 = 내 기록 원문, 고딕 = AI와 화면", D-019 글꼴, didim-design.md 5장).

### 결정 (사용자 확인, 2026-11-16)
- 모든 글이 Pretendard. `frontend/src/app/layout.tsx`에서 Noto Serif KR(next/font/google)을 빼고, `globals.css`의 `--font-serif` 토큰과 화면 5곳의 `font-serif`를 지웠다.
- 인용 크기 토큰 `text-quote`(14 / 155%)와 인용 모양(왼쪽 2px 줄 · 낫표 · 출처 줄, `SourceQuote`)은 그대로 둔다.

### 결과로 생기는 제약
- 설계 원칙 7의 글꼴 규칙이 없어진다(CLAUDE.md 고침). "어디서 온 글인가"는 근거 칩 · 출처 줄 · 인용 모양으로만 보인다(D-003 근거 우선은 그대로).
- Figma(D-019 원본)의 원문 인용 컴포넌트는 명조로 남는다 — Figma는 고치지 않는다(사용자 확인 2026-11-16). 글꼴만은 Figma가 아니라 이 결정이 원본이다(D-019의 예외).
- 글꼴 파일을 덜 받는다(구글 글꼴 요청 없음).

### 이 결정을 바꿔야 하는 조건
- 근거 패널에서 내 기록과 AI 글이 헷갈린다는 사용자 확인 · 피드백이 나오면 글꼴 대신 다른 표시(색 · 배지)부터 검토한다.
