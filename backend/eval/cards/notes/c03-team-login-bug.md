# 팀 프로젝트 3주차 — 로그인 풀림 문제

## JWT 구조 복습
JWT는 헤더, 페이로드, 서명 세 부분을 점으로 이어 붙인 문자열이다. 서버는 서명을 확인해 위조 여부만 판단하고, 세션처럼 서버에 상태를 저장하지 않는다. 그래서 액세스 토큰의 만료 시간을 짧게 두고 리프레시 토큰으로 다시 발급받는 구조를 많이 쓴다.

## 로그인이 30분마다 풀리던 버그
4명이 같이 만드는 스터디 모집 앱에서, 글을 쓰다가 30분쯤 지나면 로그인이 풀려 작성 중인 글이 날아간다는 제보가 QA 시트에 3건 올라왔다. 인증 쪽은 내가 맡은 부분이었다.

액세스 토큰 만료가 30분인데, 프론트에서 401을 받았을 때 리프레시 요청을 보내는 코드가 axios 인터셉터에 빠져 있었다. 인터셉터에 401이면 토큰을 다시 받고 원래 요청을 한 번 더 보내는 로직을 넣었다. 리프레시 요청이 동시에 여러 번 나가지 않도록 진행 중인 요청 하나를 공유하게 했다.
