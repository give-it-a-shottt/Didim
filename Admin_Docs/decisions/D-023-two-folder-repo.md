# D-023 레포는 frontend/(npm) + backend/(uv) 두 폴더로 둔다

## 한눈에 보기 (코드 몰라도 OK)
상태: [통과] 사용자가 골랐어요(2026-11-13, Q-013).
무엇을: 화면(Next.js)은 `frontend/`에서 npm으로, 서버(FastAPI)는 `backend/`에서 uv로 따로 설치 · 실행해요. 둘을 묶는 모노레포 도구(turborepo 등)는 쓰지 않아요.
왜: 이 구조로 5주째 만들었고, 프로젝트 크기에 비해 묶는 도구로 얻는 게 작아서요.

## 개발자 상세
### 후보
| 후보 | 장점 | 단점 |
|---|---|---|
| A. 두 폴더 + npm + uv (선택) | 언어별 도구 그대로, 설정이 적음 | 명령을 폴더마다 따로 실행 |
| B. 모노레포 도구(turborepo · nx) | 명령 하나로 둘 다 실행 · 캐시 | 파이썬 쪽 지원이 약함, 설정이 늘어남 |

### 결정
- A. 로컬에서는 Next.js가 `/api/*`를 FastAPI로 넘기는 프록시(rewrites)로 같은 주소처럼 쓴다(D-010).

### 이 결정을 바꿔야 하는 조건
- 배포(Q-012)에서 두 서비스를 한 번에 빌드 · 배포해야 하는 제약이 생기면 다시 본다.
