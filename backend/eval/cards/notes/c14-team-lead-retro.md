# 졸업 프로젝트 팀장 회고

## 팀장으로 일정 관리와 의견 조율
5명이 함께한 졸업 프로젝트(전시 예약 웹 서비스)에서 팀장을 맡았다. 중간 발표 2주 전까지 기능의 절반이 끝나지 않았고, 프론트엔드와 백엔드 담당이 API 모양을 두고 사흘째 의견이 갈려 있었다.

기능을 꼭 필요한 것과 나중에 할 것으로 나눠 중간 발표 범위를 줄이고, 매주 월요일 15분 회의에서 각자 막힌 것만 말하게 했다. API 모양은 두 사람과 같이 화면 하나를 끝까지 그려 보며 필요한 필드를 맞췄다.

## 디자이너와 화면 기준 맞추기
같은 프로젝트에 시각디자인과 학생 한 명이 함께했는데, 시안과 구현 화면의 간격과 색이 화면마다 조금씩 달라서 매번 수정 요청이 왔다.

디자이너와 함께 간격 단계(4 · 8 · 16 · 24px)와 색 이름 8개를 정하고, CSS 변수로 옮겨 모든 화면이 그 값만 쓰게 했다. 시안을 주고받을 때도 그 이름으로 말했다.

시안과 다르다는 수정 요청이 한 주 평균 12건에서 2건으로 줄었다.

## 내년에 할 일
다음 프로젝트에서는 처음부터 일정을 공유 캘린더에 올리고, 기능 범위를 첫 주에 정해 두고 싶다.
