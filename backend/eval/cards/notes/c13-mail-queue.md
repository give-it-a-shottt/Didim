# 행사 신청 메일 비동기 처리 기록

## 메일 발송을 메시지 큐로 분리
동아리 행사 신청 서비스(Spring Boot)에서 신청 버튼을 누르면 확인 메일을 보낸 뒤에야 응답이 와서, 신청 완료까지 평균 3.2초가 걸렸다. 메일 서버가 느린 날에는 10초를 넘기기도 했다.

신청 저장까지만 요청 안에서 처리하고, 메일 발송은 RabbitMQ 큐에 메시지로 넣은 뒤 따로 도는 소비자가 보내게 바꿨다.

신청 응답 시간이 평균 3.2초에서 0.3초로 줄었다.

## 세미나에서 들은 Kafka 사례
개발자 세미나에서 한 배달 서비스가 주문 이벤트를 Kafka로 흘려 보내 하루 수천만 건을 처리한다는 발표를 들었다. 파티션을 늘려 소비자를 수평으로 늘리는 구조가 인상 깊었다.
