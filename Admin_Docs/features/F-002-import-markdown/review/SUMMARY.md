## 참고 (지적 아님)
- 줄바꿈: 3차까지는 `splitlines`라 `\v` `\f` ` ` 등도 줄바꿈으로 봤고, 4차는 `\n`만 봄(읽을 때 `\r\n` · `\r`은 `\n`으로 맞춤). CommonMark 기준으로 4차가 맞고 위치는 두 경우 모두 정확함 — R2가 의도 확인용으로 적음. 메인 판단: 의도한 동작(마크다운 줄 끝 규칙에 맞춤).
