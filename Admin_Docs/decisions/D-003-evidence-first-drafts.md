# D-003 근거 우선 — 문장마다 근거, 지어낸 내용은 저장하지 않는다

## 한눈에 보기 (코드 몰라도 OK)
상태: [통과] 사용자가 골랐어요(2026-11-05 · 2026-11-07).
무엇을: AI가 쓴 자소서 문장마다 어느 경험 카드 · 노트에서 왔는지 근거 칩을 붙여요. 근거가 없는 문장은 경고로 표시하고, 근거 없는 문장이 남은 채로 "제출"로 바꾸면 "근거 없는 문장 2개가 있어요" 확인창이 떠요. 경험 카드에는 AI가 지어낸 내용을 저장하지 않고, 사용자 답과 근거 링크만 남겨요.
왜: AI가 대신 써 주는 서비스는 이미 많고, 지어낸 문장 · AI 티가 오히려 불리해요. 디딤은 "내 기록에 근거한 초안"이 차별점이에요.

## 개발자 상세

### 결정
- 문장 단위로 근거(카드 · 노트 · 위치)를 저장한다. 화면은 문장 끝 근거 칩 1개(여러 개면 `카드 3 +1`).
- 근거 검사는 에이전트 루프(쓰기 → 검사 → 고치기). 단순 버전(규칙 기반)을 3~4주차에 먼저 돌린다(기획 검수 반영).
- 저장은 막지 않고, 제출 상태로 바꿀 때만 확인창(사용자 결정 2026-11-07).
- 완성 카드가 0개면 초안 생성을 막고 카드 만들기로 안내한다(예외 7). 그렇지 않으면 결국 AI 창작이 되기 때문.
- 노트를 지우면 그 노트를 가리키던 근거 칩은 "원문 없음"으로 바뀐다(예외 6). 노트를 고치면 "원문 수정됨 · 날짜".
- AI 초안은 시작점: 사용자가 고친 비율을 "AI 초안에서 내가 고친 부분 42%"로 보여 준다.

### 결과로 생기는 제약
- 문장 분리 · 근거 저장 때문에 자소서 데이터 모델이 "문서 = 문장 목록"이 된다.
- LLM 응답은 정해진 스키마(문장 + 근거 id)로 받고, 형식이 틀리면 재시도 · 실패 처리.
