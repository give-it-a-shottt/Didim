## 체크 항목별 근거
- 프론트 로딩 · 에러 · 빈 데이터 → readSiteUrl() 한 함수만 변경, 서버 호출 · 데이터 화면 없음 → 해당 없음
- 프론트 네트워크 실패 → 서버 호출 없음 → 해당 없음
- 프론트 입력 오류 메시지 → readSiteUrl() 메시지가 틀린 값 · 기대 형식 · 예시를 모두 담음 → 양호(서버 환경변수라 사용자 입력은 아님)
- 백엔드 응답 코드 · 트랜잭션 · DB 제약 · 외부 API → 백엔드 변경 없음 → 해당 없음
- 설정값 오류 대응 → readSiteUrl() → 파싱 실패 · 비 http/https 모두 빌드 단계에서 같은 오류로 중단, "foo:bar" · "mailto:a@b.c" · "not a url" 수동 확인
- 정상 경로 → https://a.com/x/ → origin 정리, 기본값 → localhost:3000 수동 확인
- 테스트 존재 → 프론트 테스트 없음 → Q-014 임시 처리와 관련(F-001 시작 때 추가)
- 통과 여부 → lint · tsc 통과, 빌드 정상 · 예외 수동 확인 기대대로 → 통과
