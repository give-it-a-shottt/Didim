# D-019 화면 디자인은 Figma 디딤 파일을 원본으로 옮긴다

## 한눈에 보기 (코드 몰라도 OK)
상태: [통과] 사용자가 골랐어요(2026-11-11).
무엇을: 화면을 Figma 디딤 파일(`QmJiFtWEruu2JEpNixaOop`, 04 전체 화면 · PC 1440)대로 옮겨요. Figma와 `didim-design.md`가 다르면 **Figma가 원본**이고, `didim-design.md`를 Figma에 맞게 고쳐요. 글꼴은 Pretendard(화면)와 Noto Serif KR(내 기록 원문)을 넣어요. 모바일은 따로 그리지 않고 PC 화면이 좁은 화면에서 깨지지 않을 만큼만 맞춰요.
왜: 지금까지는 "디자인은 신경 쓰지 않고 나중에 Figma 값으로 옮긴다"(2026-11-10)로 기능만 만들었어요. 그 사이 Figma에서 화면을 끝까지 그리며 바뀐 부분(예: 사이드바가 살짝 떠 보이는 그림자)이 생겨, 두 곳이 다를 때 어느 쪽을 따를지 정해야 했어요.

| 단점 | md를 Figma에 맞춰 계속 고쳐야 함 | Figma에서 바꾼 의도가 사라짐 | 질문이 많아 진행이 느림 |

### 결정 (사용자 확인, 2026-11-11)
- **A. Figma 우선.** 다른 곳을 찾으면 `didim-design.md`를 고치고 고친 목록을 사용자에게 보여 준다.
- **토큰**: Figma 변수에 있고 `globals.css`에 없는 값은 Figma 변수 이름 그대로 `@theme`에 추가한다(사용자 확인 — icon/main · icon/sub, badge/black/soft · text · line, line/input-hover, bg/dim · bg/elevated, 사이드바 그림자 `shadow-sidebar`). 이름 없는 Figma 값은 먼저 묻는다(설계 원칙 7 그대로).
- **글꼴(Q-018)**: `next/font`. Pretendard는 `next/font/local`로 레포에 둔 가변 글꼴 한 파일(`frontend/src/app/fonts/PretendardStdVariable.woff2`, 약 290KB, SIL OFL 1.1), Noto Serif KR은 `next/font/google`(굵기 400만, 한글은 조각으로 나뉘어 미리 받지 않음). 패키지 추가 없음.
  - Pretendard **Std**(자주 쓰는 한글 2,780자 + 라틴)를 고른 이유: 전체 글자판은 크기가 몇 배라 첫 화면이 느려짐. 드문 글자는 시스템 글꼴로 보인다.
- **모바일**: PC(1440) 기준. 좁은 화면(lg 1024 미만)은 사이드바를 접힘(56)으로 바꾸고, 가로 스크롤 · 겹침이 없을 만큼만 맞춘다. 모바일 전용 화면(MO 375)은 만들지 않는다.
- **순서**: 기능이 있는 화면부터 묶음으로 — ① 공통 부품 + 레이아웃 ② 기록 · 복습 ③ 기록 추가 ④ 로그인 · 설정 · 홈. 묶음마다 사용자가 화면을 확인한다. 기능이 없는 화면(CRD · APL · SET_02 · DEM · LND)은 그 기능을 만들 때 같이 옮긴다(데이터 없이 그림만 두면 가짜 화면이 되어서).
- 디자인 결과는 리뷰어가 보지 않고 사용자가 평가한다(CLAUDE.md).

### 결과로 생기는 제약
- 아이콘은 Figma에서 받은 SVG를 모양(마스크)으로만 쓰고 색은 토큰으로 칠한다(`frontend/src/components/icon.tsx`). Figma 화면 인스턴스 몇 곳은 아이콘 색이 컴포넌트 정의와 반대로 저장돼 있어(예: REV_01_001에서 선택 안 된 지원 아이콘이 검정) **컴포넌트 정의**(선택 = 검정, 기본 = icon/sub)를 따른다.
- 2차 범위(D-006) 요소는 Figma에 있어도 모양만 두고 동작은 만들지 않는다.

### 이 결정을 바꿔야 하는 조건
- Figma 파일을 더 이상 고치지 않고 코드에서 디자인을 바꾸기 시작하면 → 원본을 코드(`globals.css`)와 `didim-design.md`로 되돌린다.
