## 설계 의도 (사용자 확인 — 코드 작성 전에 채움, 문장 정리사 사용)
- 이 기능이 해결하는 문제 (사용자 확인 2026-11-18): 채용 담당자가 무엇을 하는 서비스인지, 얼마나 믿을 만한지(평가 수치)를 30초 안에 판단할 곳이 없다.
- 완료 기준 (사용자 확인 2026-11-18):
  1. `/` 첫 화면(100vh)에 헤드라인 · [내 기록으로 시작하기](→ /login) · [샘플 보기](→ /demo) · 실제 화면(샘플 실제 초안을 자소서 화면과 같은 모양으로 그린 카드) · 평가 수치(→ /report)가 보인다. (사용자 승인 2026-11-18 — Figma 재구성)
  2. 평가 수치는 `GET /api/report` 최근 회차에서 읽는다. 못 읽으면 수치 칸만 숨기고 [평가 리포트] 링크는 남긴다.
  3. 스토리 구간(250vh — 사용자 승인 2026-11-18)에서 스크롤에 맞춰 ① 샘플 AI 초안 → ② 근거가 없거나 카드에 없는 낱말이 섞인 문장에 ⚠ 밑줄(사용자 확인 2026-11-18, 1차 리뷰 R4) → ③ 근거 있는 문장엔 원문 각주가 붙고 근거 없는 문장은 빠진다. 문장 · 각주는 샘플 실제 결과를 글자 그대로.
  4. [건너뛰기] 링크가 있고, 움직임 줄이기 설정이면 움직임 없이 완성 상태를 보여 준다.
  5. 공개 페이지 SEO: title · description, h1 하나, 서버 렌더링, 검색 노출.
- 화면 · 컴포넌트 (사용자 확인 2026-11-18): `/` → (landing)/page.tsx, LND_01_001. 위 메뉴(로고 · 기능 · 평가 방법 · 샘플 보기 · 로그인) · 히어로 · 스토리 · 기능 카드 3장(고정 구간) · 평가 방법 · 마지막 시작 안내 · 푸터 — Figma 디딤 랜딩(29:1373) 배치. (사용자 승인 2026-11-18)
  - 스토리는 전체 3단계(D-007 기본안).
  - 첫 화면 평가 수치는 '잡아내기' 3개: 지어낸 문장 경고율 · 심은 면접 질문 잡은 비율 · 없는 근거로 만든 매칭 수. 평가 데이터 규모와 모델을 작게 함께.
  - 이미 로그인한 사람에게도 랜딩을 그대로 보여 주고, [시작하기] 대신 [홈으로](→ /home)를 보인다.
  - 바닥글 링크는 있는 페이지(평가 리포트 · 샘플 체험)만 둔다. Figma의 소개 · 이용약관 · 개인정보 처리방침 · 문의는 페이지가 없어 넣지 않는다. (사용자 승인 2026-11-18)
- API (사용자 확인 2026-11-18): 새 API 없음. 기존 공개 `GET /api/report`를 쓴다.
- 데이터 (사용자 확인 2026-11-18): 표 변경 없음. 실제 화면 · 스토리 내용은 샘플 계정의 실제 AI 초안 · 근거 검사 결과.
