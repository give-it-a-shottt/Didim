# 정렬 알고리즘

## 퀵 정렬
퀵 정렬은 기준값(피벗)을 하나 골라 그보다 작은 값과 큰 값으로 나눈 뒤 양쪽을 다시 같은 방식으로 정렬한다. 평균 시간 복잡도는 O(n log n)이지만, 피벗을 계속 가장 작거나 가장 큰 값으로 고르면 O(n²)까지 느려진다.

## 병합 정렬
병합 정렬은 배열을 절반으로 계속 나눈 뒤 정렬된 두 부분을 합치면서 정렬한다. 입력이 어떻든 최악의 경우에도 O(n log n)을 보장하지만, 합치는 과정에서 원래 배열 크기만큼의 추가 메모리 O(n)이 필요하다.

## 안정 정렬
안정 정렬은 값이 같은 원소들의 원래 순서를 정렬 뒤에도 유지한다. 병합 정렬과 삽입 정렬은 안정 정렬이고, 일반적인 퀵 정렬과 힙 정렬은 안정 정렬이 아니다. 이름순으로 정렬한 목록을 다시 나이순으로 정렬할 때 같은 나이 안에서 이름순을 유지하려면 안정 정렬이 필요하다.

## 삽입 정렬
삽입 정렬은 앞쪽의 정렬된 부분에 원소를 하나씩 알맞은 자리에 끼워 넣는다. 최악은 O(n²)이지만 이미 거의 정렬된 배열에서는 O(n)에 가깝게 빠르다. 그래서 원소가 적은 구간에서는 퀵 정렬보다 빠르기도 하다.

## 파이썬의 sorted
파이썬의 `sorted()`와 `list.sort()`는 Timsort를 쓴다. Timsort는 병합 정렬과 삽입 정렬을 섞은 방식으로, 이미 정렬된 구간(run)을 찾아 활용하며 안정 정렬이다. `sorted()`는 새 리스트를 돌려주고, `list.sort()`는 원래 리스트를 바꾸고 None을 돌려준다.
