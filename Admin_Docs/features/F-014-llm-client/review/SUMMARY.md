## 겹친 지적 묶음 (메인)
- A. 사용량 집계가 적게 나옴 — R1 · R2 · R3 공통. `StructuredReply.attempts`는 형식 재시도만 세고 연결 재시도는 세지 않음(HTTP 최대 4번인데 2로 나옴). 토큰은 마지막 답 것만 남고, 실패 예외에는 사용량이 없음.
- B. 전체 시간 상한 없음 — R2. 60초는 바이트 사이 간격이라, 응답이 안 오면 최대 약 4분 20초 기다림.
- C. JSON 꺼내기 — R2(코드 블록 정규식이 긴 공백에서 느려짐, 공백 16,000자에 1.26초) · R3(앞뒤 설명에 중괄호가 있으면 잘못 잘림, 테스트 3가지뿐).
- D. 승인 없이 들어간 것 — R4. `LLMRequestError` 분리, 재시도 대기 1초 · 연결 5초 · 408과 깨진 본문 재시도 · 키는 https만 · local 기본 주소 Ollama.
- E. 작은 것 — 설명의 `EXAONE_BASE_URL` 표기(R4), local에서도 "EXAONE_API_KEY 확인" 문구(R1), 402 분류(R3, 추정), 로그 없음(R3), 테스트 빠진 분기(R3), RecursionError(R2), 예외 문구에 답 값이 섞일 수 있음(R2), mock 기본 답이 JSON이 아님(R3).
