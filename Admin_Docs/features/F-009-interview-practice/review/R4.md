## 지적 (있을 때)
- [신규] [주의] [확실] 같은 글 질문을 합치고 나면, 질문이 전부 다른 카드로 합쳐진 카드가 '질문 없는 카드 N장 — 면접 질문은 카드 상세에서 만들어요'에 들어간다. 그 카드에는 질문이 이미 있어서 카드 상세에 [면접 질문 만들기] 버튼이 없다(카드당 한 번). 안내가 사실과 다르고, 링크를 눌러도 할 일이 없다 — 위치: backend/app/services/interview_service.py `get_application_interview` · `_merge_same_questions`(합쳐져 0개가 된 카드도 `questions=[]`로 남김), frontend/src/components/interview-workspace.tsx `cardsWithoutQuestions`(`card.questions.length === 0`) · `EmptyRows` — 확인한 범위: 패킷의 두 파일 코드, test_interview_tab_merges_same_questions_keeping_the_answered_one(`[[], [same.id]]`로 이 상태를 확인), feature.md 완료 기준 2와 정한 것 ③ ⑤. ⑤는 '합치기'만 정했고, 합쳐진 카드를 어떻게 보일지는 정하지 않았다 — 고치는 방법: `CardInterviewOut`에 `has_questions`(합치기 전에 질문이 있었는지) 같은 값을 하나 더해, 화면의 '질문 없는 카드'는 합치기 전에도 질문이 없던 카드만 센다. 합쳐진 카드는 '다른 카드와 겹쳐 하나로 모았어요' 같은 한 줄로 두거나 목록에서 뺀다. 문구는 사용자에게 받는다. 값을 더하면 api-list(GET /api/applications/{id}/interview)와 `lib/interview.ts`도 같이 고친다.
- [신규] [제안] [추정] 완료 기준 3의 '같은 질문은 다른 공고에서도 같은 메모를 본다'가 질문 행(카드에 붙음) 기준으로만 맞는다. ⑤로 글이 같은 질문을 합쳤으므로 '같은 질문'이 행인지 글인지 사용자가 정해야 한다. 지금은 공고 X에서 카드 1·2에 같은 글의 질문이 있고 카드 1 행에 답을 쓰면, 카드 2만 매칭된 공고 Y에서는 같은 글의 질문인데 메모가 비어 보인다. 둘 다 답했다면 합친 화면에서 안 남은 쪽 메모는 가려진다(삭제되지는 않음) — 위치: interview_service.py `_merge_same_questions`, `update_memo`, data-model.md interview_questions.memo 설명('질문이 카드에 붙어 어느 공고에서 봐도 같음') — 확인한 범위: 패킷의 코드 · 설계 의도 · 데이터 모델 발췌. 코드 경로는 확인했고, 사용자가 '같은 질문'을 어느 쪽으로 뜻했는지는 문서만으로 알 수 없어 [추정]. 사용자에게 '같은 글의 질문이면 다른 카드 행에 쓴 메모도 이어서 보일지, 카드마다 따로일지'를 물으면 [확실]이 된다 — 고치는 방법: OPEN_QUESTIONS에 Q-0xx로 추가한다. 카드마다 따로라면 api-list · screens에 '같은 글 질문의 메모는 카드마다 따로, 합친 화면에는 답한 쪽만 보임'을 한 줄 적는다.
- [신규] [제안] [추정] 카드를 지우면 질문과 내 답 메모도 CASCADE로 같이 지워진다. 사용자가 쓴 글이 사라지는데 api-list의 DELETE /api/cards/{card_id} 설명은 '칸도 같이'까지만 있고, 삭제 확인 문구에 메모가 같이 지워진다는 안내가 있는지 패킷으로는 모른다 — 위치: api-list.md DELETE /api/cards/{card_id}, frontend card-editor.tsx의 삭제 확인(패킷에 없음) — 확인한 범위: 패킷의 api-list 발췌 · 데이터 모델(`ON DELETE CASCADE`) · 테스트. card-editor.tsx의 삭제 확인 문구를 직접 열어 메모 안내가 있으면 문서만 고치면 되고, 없으면 [확실]이 된다 — 고치는 방법: api-list 삭제 설명에 '면접 질문 · 메모도 같이'를 적고, 질문이 있는 카드는 삭제 확인에 한 줄 더한다(문구는 사용자 확인).
