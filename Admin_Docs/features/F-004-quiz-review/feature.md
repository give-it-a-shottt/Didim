# F-004 퀴즈 복습 · 복습 주기 · 오답노트

## 한눈에 보기 (코드 몰라도 OK)
상태: [주의] 백엔드 · 화면 구현 끝(코드 커밋 전, 2026-11-11). 다음은 평가 세트 → 리뷰.
언제: 3주차
무엇을: 노트에서 객관식 · OX 문제를 만들고(D-006), 맞히면 간격을 늘려(당일 → 1 → 3 → 7 → 14일) 다시 내요. 틀린 문제는 오답노트로, 2번 연속 맞히면 빠져요
왜: 기록을 올려도 다시 보지 않으면 잊혀서, 근거가 확인된 문제로 정해진 간격마다 다시 풀게 하려고요.

## 설계 의도 (사용자 확인 — 코드 작성 전에 채움, 문장 정리사 사용)
- 이 기능이 해결하는 문제: 공부 기록을 올려도 다시 보지 않아 잊힌다. 내 기록에서 근거가 확인된 문제를 만들고, 정해진 간격으로 다시 풀게 해서 기억에 남긴다. (사용자 확인, 2026-11-10)
- 정한 것 (사용자 확인, 2026-11-10 — 선택지로 받음):
  - 문제는 노트 상세의 [문제 만들기]로 노트 하나씩 만든다(요청 한 번에, 백그라운드 작업 · 이어 보기 없이). 기록 추가 직후 자동 만들기는 Q-008을 정한 뒤.
  - 근거 검사: 문제마다 근거 조각과 "정답의 근거가 되는 원문 문장"을 같이 받고, 그 문장이 조각 안에 글자 그대로 있는지 서버가 확인한다. 없으면 그 문제는 버리고 버린 개수를 로그로 남긴다(평가 수치). 해설에는 근거 칩 → 노트 상세 위치 강조(F-003).
  - 복습 단위: 기록 · 복습 홈의 '오늘 복습'(모든 노트에서 오늘 차례인 문제를 한 세션으로) + 노트 상세의 [이 노트 풀기](그 노트 문제만).
  - 문제 수: 조각마다 1개, 노트당 최대 10개(짧은 조각은 건너뜀).
  - AI 호출: [문제 만들기] 한 번에 노트 하나를 한 번에 보낸다(고른 조각들을 한 요청에 담아 문제 최대 10개를 받음). 하루 상한 30과 맞추려고 — 조각마다 부르면 노트 3개 정도에서 막힘. (사용자 확인, 2026-11-11)
  - 짧은 조각: 공백을 뺀 글자 수 80자 미만은 건너뜀(config 상수, 평가 뒤 조정). 남은 조각이 10개보다 많으면 노트 전체에서 고르게 퍼뜨려 10개(같은 노트면 항상 같은 조각 — 재현 가능). 이미 문제가 있는 노트에서 다시 누르면 AI를 부르지 않고 409 "이미 문제가 있어요"(다시 만들기는 나중). (사용자 확인, 2026-11-11)
  - 오답노트에서 빠지려면 서로 다른 복습일에 두 번 연속 맞혀야 한다. 같은 날 미리 맞힌 것은 세지 않는다. (사용자 확인, 2026-11-11 — 1차 리뷰 R4)
  - 틀리면 간격 0단계 · 오늘 다시(오늘 복습에 다시 나옴). 복습일 전에 미리 풀면([이 노트 풀기]) 틀린 것은 그대로 반영(0단계 · 오답노트), 맞힌 것은 기록만 남기고 간격은 복습일이 됐을 때만 늘림. (사용자 확인, 2026-11-11)
- 완료 기준(3주차): (사용자 확인, 2026-11-10)
  1. 노트 상세 [문제 만들기] → 조각마다 1개(짧은 조각 건너뜀), 노트당 최대 10개, 객관식(4지) · OX.
  2. 문제마다 근거 조각 + 원문 인용 문장을 저장하고, 인용이 조각 안에 글자 그대로 없으면 버리고 버린 수를 기록한다.
  3. 해설에 근거 칩 → 누르면 노트 상세 위치 강조.
  4. 풀면 채점 · 다음 복습일(당일 → 1 → 3 → 7 → 14일). 틀리면 오답노트, 2번 연속 맞히면 빠짐.
  5. 기록 · 복습 홈 '오늘 복습 N' → 한 세션, 노트 상세 [이 노트 풀기] → 그 노트만.
  6. AI 호출은 사용자당 하루 상한(30회) 안에서, 형식 오류는 재시도 후 실패 안내. 다른 사용자의 문제는 안 보인다.
  7. 가상 노트(D-005)로 '정답 · 해설이 원문과 맞는 비율'과 '버려진 문제 비율'을 재서 기록한다.
- 화면 · 컴포넌트: (IA 화면 ID 참고 — REV_01_001 · 002 · 003, REV_02_001 · 002, REV_03_001, REV_01_900)
  - 세션: (사용자 확인, 2026-11-11) 백엔드에 세션 표를 두지 않고 주소가 세션 종류 — `/quiz/today`(오늘 복습) · `/quiz/wrong`(오답노트 다시 풀기) · `/quiz/note-12`(노트 하나). 문제 목록은 시작할 때 서버 컴포넌트가 한 번 받아 고정. 결과 화면은 `?correct=&total=` 주소 값으로 이번 세션 점수만(이전 세션과의 점수 변화는 나중).
  - 기록 · 복습 홈: (사용자 확인, 2026-11-11) '오늘 복습 N' + [복습 시작] · [오답노트], 기록 검색(F-003), 노트 목록(제목 · 종류 · 조각 수 · 문제 수, 최근 것부터 최대 200개), 노트가 없으면 REV_01_900.
  - 노트 상세: 문제 칸 — 문제가 없으면 AI에 보내는 범위 안내 + [문제 만들기], 있으면 [이 노트 풀기]. 서버 문구(409 · 422 · 429 · 502 · 503)는 그대로 보여 준다.
  - 퀴즈(집중 모드): 진행바, 보기 고르고 [답 내기] → 오른쪽 패널(PC)에 맞음 · 틀림, 정답, 해설, 원문 인용, 근거 칩(→ 노트 상세 조각 강조), 다음 복습일, 오답노트 들어감 · 빠짐.
- API: (사용자 확인, 2026-11-10) `POST /api/notes/{id}/quizzes`(문제 만들기), `GET /api/notes/{id}/quizzes`(그 노트 문제), `GET /api/reviews/today`(오늘 복습), `POST /api/quizzes/{id}/answer`(답 제출 → 채점 · 해설 · 근거 · 다음 복습일), `GET /api/wrong-answers`(오답노트). 답 제출은 화면에서 TanStack Query(D-012). + `GET /api/notes`(내 노트 목록 — 홈 노트 목록용, 사용자 확인 2026-11-11).
- 데이터: (사용자 확인, 2026-11-10) 버전 파일 0004 — `quizzes`(노트 · 근거 조각, 유형, 문제, 보기, 정답, 해설, 근거 인용 문장 + 원문 위치), `quiz_reviews`(다음 복습일 · 간격 단계 · 연속 정답 수 · 오답노트 여부), `quiz_attempts`(고른 답 · 맞음 · 시각), `quiz_generation_logs`(요청 · 남긴 · 버린 수와 이유 — 평가). 모두 user_id(FK CASCADE) 조건(D-004).
  - 동시 클릭: (사용자 확인, 2026-11-11) `note_quiz_claims`(note_id 유니크) — AI를 부르기 전에 노트를 선점해 동시에 두 번 눌러도 AI는 1번, 두 번째는 409 "만드는 중". 실패 · 모두 버려짐 · 저장 실패면 선점 해제, 성공이면 남김, 5분 넘은 선점은 새 요청이 가져감. 안전망으로 `quizzes.chunk_id` 유니크(조각마다 1개). 0004에 같이 생성.
  - 사용량: (사용자 확인, 2026-11-11 — D-018) 호출 · 토큰은 공용 표 `ai_usage_logs`(0004에 같이 생성)에 기록하고, 하루 상한 30은 그 표의 실제 호출 수 합계로 센다. 하루는 한국 시간 0시 기준('오늘 복습'도 같은 기준). 부르기 전에 확인하고 끝난 뒤 기록 — 동시 요청 · 재시도로 조금 넘칠 수 있음.
