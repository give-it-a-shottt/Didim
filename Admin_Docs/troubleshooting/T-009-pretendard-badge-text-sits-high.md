# T-009 배지 안의 한글이 가운데가 아니라 위로 치우쳐 보임(Pretendard)

## 한눈에 보기 (코드 몰라도 OK)
상태: [통과] 해결했어요(2026-11-13).
무슨 문제였나: 지원 목록의 '준비' · '작성 중' 배지에서 글자가 배지 가운데가 아니라 위로 붙어 보였어요(사용자 화면 확인 때 발견). 가운데 정렬은 되어 있는데도요.
어떻게 해결했나: 배지를 6배로 확대해 찍어 재 보니 글자가 위로 약 1.5px 치우쳐 있었어요. 배지 높이는 그대로 두고 위 여백 3px로 글자를 내려 맞췄어요. 배지 모양을 상수 하나로 모아 다른 화면 배지도 같이 고쳐졌어요.

## 개발자 상세
- 증상: `inline-flex h-5 items-center` 배지(글자 12px · 줄 높이 1.45)에서 글자 아래 여백이 위보다 큼 — 6배 확대 시 위 약 3px · 아래 약 6px.
- 원인: Pretendard 한글 글리프가 글꼴의 위아래 공간(ascent · descent) 안에서 위쪽에 그려진다. `items-center`는 줄 상자를 가운데에 놓을 뿐 글자 모양의 가운데를 맞추지 않는다. (`text-box: trim-both cap alphabetic`은 이 배지에서 차이가 없었다.)
- 해결: `frontend/src/lib/ui-classes.ts`에 `BADGE_SHAPE`(모양만, 색 없음) + `pt-0.75`(위 3px → 글자가 약 1.5px 내려감). 배지 Soft · Line과 지원 화면의 상태 · D-day 배지가 같이 씀.
- 측정 방법: 개발 서버의 아무 공개 페이지(`/`)를 Playwright(`channel: "chrome"`, `deviceScaleFactor: 6`)로 열고, 배지 span을 넣어 스크린샷으로 비교.
  - ⚠️ Tailwind는 소스에 쓰인 클래스만 CSS로 만든다. 아직 안 쓰는 클래스(예: `pt-1`)를 페이지에 넣으면 스타일이 없어서 바뀌지 않은 것처럼 보인다 → 비교할 땐 같은 값을 inline style로 넣는다.
- 재발 방지: 작은 배지 · 칩에 새 모양을 만들 때 `BADGE_SHAPE`를 쓴다. 글자 크기를 바꾸면 위 여백을 다시 잰다.
