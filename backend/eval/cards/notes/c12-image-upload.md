# 중고거래 앱 이미지 업로드 개선

## 업로드 이미지 썸네일 생성
중고거래 사이드 프로젝트에서 사용자가 올린 사진을 원본 그대로 저장하고, 목록 화면에서도 원본을 불러왔다. 사진 한 장이 평균 4MB라 목록 화면 하나에 40MB 가까이 받아야 했고, 서버 저장 공간도 한 달 만에 절반이 찼다.

Node.js 서버에서 업로드를 받을 때 sharp로 긴 변이 1280px인 본문용 이미지와 320px 썸네일을 WebP로 만들어 저장하고, 원본은 저장하지 않게 바꿨다. 목록 화면은 썸네일만 불러오게 했다.

목록 화면에서 받는 용량이 40MB에서 1.5MB로 줄었고, 사진 한 장의 저장 용량도 평균 4MB에서 350KB가 됐다.

## 이미지 포맷 비교 정리
JPEG는 사진에, PNG는 투명 배경과 선이 뚜렷한 그림에 맞다. WebP는 같은 화질에서 JPEG보다 25~35% 작고 투명 배경도 된다. AVIF는 더 작지만 만드는 데 시간이 오래 걸린다.
