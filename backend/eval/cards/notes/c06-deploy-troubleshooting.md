# 배포 트러블슈팅 모음

## 도커 이미지 크기 줄이기
개인 프로젝트 백엔드의 도커 이미지가 1.2GB여서 서버에 올릴 때마다 5분 넘게 걸렸다. 무료 서버의 디스크도 금방 찼다.

베이스 이미지를 python:3.12에서 python:3.12-slim으로 바꾸고, 빌드 도구는 첫 단계에서만 쓰는 멀티 스테이지 빌드로 나눴다. .dockerignore에 테스트 폴더와 .git을 넣었다.

이미지가 210MB로 줄었고 배포 시간도 1분 안쪽이 됐다.

## GitHub Actions 빌드 시간
PR마다 도는 CI가 매번 의존성을 처음부터 설치해서 8분씩 걸렸다. 리뷰를 요청하기 전에 CI가 끝나길 기다리는 시간이 아까웠다.

actions/cache로 패키지 캐시를 잠금 파일 해시 기준으로 저장하게 바꿨다.

## 블로그에서 읽은 사례
어떤 회사 기술 블로그에서 모노레포 CI를 바뀐 패키지만 테스트하도록 바꿔 40분 걸리던 빌드를 7분으로 줄였다는 글을 읽었다. 우리 프로젝트는 작아서 아직 필요 없지만 기억해 두려고 적는다.
