[가상] 바구니마켓 · Java 백엔드 개발자 (신입)

바구니마켓은 동네 가게의 신선식품을 당일 배송하는 커머스 서비스를 운영합니다. 이벤트 때마다 몰리는 주문을 안정적으로 처리할 백엔드 개발자를 찾습니다.

주요 업무
- 주문 · 쿠폰 · 재고 API 개발과 운영
- 이벤트 트래픽 대응

자격 요건
- 동시 요청 상황에서 데이터 정합성을 지켜 본 경험
- 메시지 큐로 비동기 처리를 구현해 본 경험
- 테스트 코드를 작성해 본 경험

우대 사항
- JPA 사용 중 N+1 문제를 해결해 본 경험
- MSA 환경에서 서비스를 운영해 본 분

복지
- 자율 출퇴근, 장보기 포인트 지급
