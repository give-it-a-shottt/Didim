# D-029 샘플 체험은 샘플 계정 세션으로 들어가고, 샘플 · 평가 리포트는 로그인 없이 공개한다

## 한눈에 보기 (코드 몰라도 OK)
상태: [통과] 사용자가 골랐어요(2026-11-17, F-010 설계 의도 ③). 만드는 건 F-010(7주차).
무엇을: [샘플로 체험하기]를 누르면 샘플 사용자로 들어가 기존 화면을 그대로 둘러봐요. 쓰기와 AI 호출은 서버가 막아요. 샘플 체험과 평가 리포트는 구글 로그인 없이 볼 수 있어요. 리포트는 회원 화면(`/settings/report`)에서 공개 화면(`/report`)으로 옮겨요.
왜 (사용자 선택): 면접관이 README · 랜딩 링크로 로그인 없이 바로 실제 기능과 수치를 보게 하려고 추천안을 골랐어요. D-025가 F-010으로 미뤄 둔 "샘플 계정을 어떻게 쓰고 읽기 전용을 어디서 막는지"를 정하는 결정이에요(D-025는 그대로).

## 개발자 상세

| 후보 | 장점 | 단점 |
|---|---|---|

### 결정
- 샘플: `/demo`는 입구(안내 한 장). [샘플로 체험하기] → 샘플 사용자 세션 → 기존 회원 화면을 그대로 본다. '샘플' 배지 · [체험 끝내기]를 보인다. 쓰기 · AI 호출은 서버가 막는다. 샘플 화면은 noindex.
- 리포트: SET_02_001을 공개 페이지 `/report`로 옮기고 검색에 노출한다.
- 세부 방식(샘플 세션을 어떻게 여는지, 쓰기를 어디서 막는지, 로그인한 사용자가 체험할 때 세션 처리)은 F-010 설계 의도 ④ · ⑤에서 정한다.
- 덧붙임(사용자 선택 2026-11-18, F-010 2차 리뷰 R4): 샘플 세션에서도 기록 검색(`GET /api/search`)은 쓸 수 있게 두고, 검색 로그는 남기지 않는다(샘플은 DB에 쓰지 않음). 다른 방법 — 샘플에서는 검색을 막기 — 은 고르지 않았다.
- 덧붙임(사용자 선택 2026-11-18, F-010 3차 리뷰 R4): 샘플 시드는 공개되지 않는 임시 계정에 다 채운 뒤 한 번에 바꿔 끼운다. 시드가 실패 · 중단하면 지금 샘플을 그대로 둔다(체험은 계속 열림). 평가를 새로 돌린 뒤 시드가 실패하면 리포트(새 수치)와 샘플(옛 데이터)이 잠시 어긋날 수 있다 — 시드가 종료 코드 1로 알리므로 다시 돌린다. 다른 방법 — 실패하면 샘플을 내려 503 — 은 고르지 않았다.

### 이 결정을 바꿔야 하는 조건
- 샘플 세션으로 쓰기 · AI 호출이 새는 경로가 막기 어려울 만큼 많으면 B(`/demo` 읽기 전용 화면)를 다시 본다.
- 샘플 데이터를 사람마다 고쳐 보게 해야 하면 D-025와 함께 다시 본다.
