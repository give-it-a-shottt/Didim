### 다시 재기

```bash
cd backend
uv run --env-file .env python -m scripts.eval_all nvidia --pause 3   # 퀴즈 · 카드 · 매칭 · 자소서 · 면접
uv run python -m scripts.eval_all --rescore eval/summary/run-<시각>.json   # 사람 판정을 적은 뒤
uv run python -m scripts.eval_all --readme                                 # 이 표를 최근 회차로
```
