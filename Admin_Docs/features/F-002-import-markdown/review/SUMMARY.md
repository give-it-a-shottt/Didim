## 신규 지적
- A2. [신규] [위험] [확실] 주소 끝 `%0A`(줄바꿈)로 업로드 가드를 비켜 감 — R2. 가드는 `scope["path"]`를 문자열로 정확히 비교하는데, 라우터의 경로 정규식은 `$`가 끝 줄바꿈 앞에서도 맞아서 `/api/notes/import\n`이 엔드포인트로 들어간다. 쿠키 없이도 본문을 끝까지 받고, 로그인한 사용자는 21MB 상한 없이 올릴 수 있다. 메인 재현: 보통 경로 401 · 읽은 본문 0바이트, 줄바꿈 경로는 본문 1MB를 읽음. `backend/app/api/upload_limit.py:31`
- F2. [신규] [주의] [확실] 조각 상한(2,000)을 나누기가 다 끝난 뒤에 확인해서, 상한을 훨씬 넘는 1MB 파일도 끝까지 나누며 메모리 약 212MB · 0.8초를 씀(20개면 약 20초) — R2. `chunking.py`, `import_service.py:117`

- N. [신규] [제안] "로그인이 필요해요." 문구가 upload_limit.py:21과 deps.py:30 두 곳 — R1.
