# D-004 처음부터 남이 쓰는 서비스로 만든다

## 한눈에 보기 (코드 몰라도 OK)
상태: [통과] 사용자가 골랐어요(2026-11-05).
무엇을: 나 혼자 쓰는 도구가 아니라 다른 사람도 가입해서 쓰는 서비스로 만들어요. 그래서 1주차부터 로그인, 사용자별 데이터 분리, AI 사용량 제한, 데이터 삭제를 넣어요.
왜: 자소서 · 경험은 민감한 정보라, 나중에 붙이면 구조를 갈아엎어야 해요.

## 개발자 상세

### 결정
- 모든 조회 · 벡터 검색에 사용자 ID 조건을 건다. 다른 사용자의 기록이 검색되면 버그.
- 사용자별 하루 AI 호출 수 · 토큰 상한. 한도에 걸리면 부분 결과를 보존하고 남은 사용량을 안내(예외 4).
- LLM에는 필요한 조각만 보내고, 무엇을 보내는지 안내한다.
- 설정에서 데이터 삭제(확인 모달).
- 작성 중 로그인이 만료되면 입력 내용을 임시 저장하고, 다시 로그인하면 같은 자리로 돌아온다(예외 2).

### 정해진 것
- 로그인 방식: 구글 로그인으로 시작한다([F-001](../features/F-001-account-isolation/feature.md) 설계 의도, 2026-11-07). 로그인 처리 위치는 [D-010](D-010-auth-in-fastapi.md).
