# 용어집

코드를 몰라도 문서를 읽을 수 있게, 자주 나오는 말을 쉬운 말로 풀어요.

| 용어 | 쉬운 말 |
|---|---|
| 프론트(프론트엔드) | 브라우저에 보이는 화면을 그리는 코드 (디딤은 Next.js) |
| 백엔드(서버) | 화면 뒤에서 데이터를 찾아 주고 계산하는 프로그램 (디딤은 FastAPI) |
| API | 화면이 서버에 "이거 줘" 하고 보내는 요청의 약속된 형식. 식당 주문서 같은 것 |
| 컴포넌트 | 화면을 이루는 레고 블록. 버튼, 근거 칩 같은 조각 |
| 디자인 토큰 | 색 · 글자 크기 · 간격에 붙인 이름. `primary/default` = 시안 버튼처럼 이름으로 부르면 값이 한곳에서 바뀌어요 |
| 대비(명도 대비) | 글자와 배경의 밝기 차이. 4.5 : 1 이상이어야 잘 읽힌다는 접근성 기준(WCAG)이 있어요 |
| 접근성 | 키보드만 쓰는 사람, 화면 낭독기를 쓰는 사람도 쓸 수 있게 만드는 것 |
| mock(목) | 진짜 대신 쓰는 가짜 데이터 · 가짜 서버. AI 키 없이도 개발 · 테스트할 수 있어요 |
| LLM | 글을 읽고 쓰는 큰 AI 모델. 퀴즈 · 카드 후보 · 자소서 초안을 만들어요 |
| 임베딩 | 글의 뜻을 숫자 목록으로 바꾼 것. 뜻이 비슷한 글은 숫자도 가까워서 "비슷한 글 찾기"가 돼요 |
| 청크(조각) | 긴 노트를 검색하기 좋게 자른 한 토막 |
| RAG | AI가 답하기 전에 내 기록에서 관련 조각을 먼저 찾아 읽게 하는 방식. 오픈북 시험 같은 것 |
| pgvector | PostgreSQL에서 임베딩(숫자 목록)을 저장하고 가까운 것을 찾게 해 주는 확장 기능 |
| BM25 | 낱말이 얼마나 겹치는지로 순위를 매기는 검색 점수 공식. 임베딩 검색과 섞어 쓰면 정확한 낱말 · 비슷한 뜻을 둘 다 잡아요 |
| 하이브리드 검색 | 키워드 검색(BM25)과 뜻 검색(임베딩)을 섞은 검색 |
| 어댑터 | 모양이 다른 입력(마크다운 · 노션)을 같은 모양으로 바꾸는 변환 플러그 |
| 에이전트 루프 | AI가 쓰고 → 스스로 검사하고 → 고치는 것을 정해진 횟수만큼 반복하는 구조 |
| 구조화 출력(스키마) | AI 답을 정해진 칸(문장, 근거 id …)에 맞춰 받는 것. 형식이 틀리면 다시 요청해요 |
| 근거 칩 | 자소서 문장 끝에 붙는 작은 표시. 누르면 그 문장이 나온 카드 · 노트 원문이 보여요 |
| 근거 없는 문장 | 어느 카드 · 노트에도 이어지지 않는 문장. AI가 지어냈을 수 있어 경고해요 |
| 근거율 | 전체 문장 중 근거가 있는 문장의 비율. 화면에는 "10문장 중 8문장에 근거가 있어요"처럼 문장으로 보여 줘요 |
| 경험 카드(STAR) | 경험 하나를 상황 · 과제 · 행동 · 결과로 정리한 카드 |
| 복습 주기(Leitner) | 맞힌 문제는 간격을 늘려(당일 → 1 → 3 → 7 → 14일) 다시 내는 방식 |
| 평가 세트 | 정답을 미리 심어 둔 가상 카드 · 공고 묶음. 고칠 때마다 같은 시험지로 채점해요 |
| 상위 3 적중률 | 정답 카드가 매칭 결과 1~3위 안에 든 공고의 비율. 높을수록 좋아요 |
| 탐지율 | 일부러 섞은 지어낸 문장 중 검사기가 잡아낸 비율 |
| 인증 | "이 사람이 누구인지" 확인하는 일. 로그인이 대표적이에요 |
| OAuth(구글 로그인) | 비밀번호를 우리 서비스에 주지 않고, 구글이 "이 사람 맞아요"라고 대신 확인해 주는 방식 |
| 세션 · 쿠키 | 로그인한 뒤 받는 출입증. 쿠키는 브라우저가 사이트마다 들고 있다가 요청마다 알아서 같이 보내는 작은 메모예요 |
| httpOnly 쿠키 | 페이지의 자바스크립트가 읽지 못하게 잠근 쿠키. 나쁜 스크립트가 끼어들어도(XSS) 출입증을 훔쳐 가지 못해요 |
| XSS | 남의 페이지에 나쁜 스크립트를 몰래 끼워 넣어 실행시키는 공격 |
| SEO | 검색 엔진(구글 · 네이버)이 내 페이지를 잘 찾고 이해하게 만드는 일 |
| 메타데이터 | 페이지 제목 · 설명처럼 화면엔 안 보이지만 검색 결과 · 링크 미리보기에 쓰이는 정보 |
| noindex | "이 페이지는 검색 결과에 올리지 마세요"라는 표시. 개인 화면에 붙여요 |
| robots.txt · sitemap.xml | 검색 엔진에게 "여긴 보지 마세요" · "이 페이지들이 있어요"를 알려 주는 안내문 |
| 시맨틱 태그 | `main` · `nav` · `h1`처럼 "이 부분이 무슨 역할인지" 알려 주는 HTML 태그 |
| 서버 상태 | 서버(DB)에 원본이 있는 데이터. 화면은 복사본을 들고 있어서, 언제 다시 받아 올지가 중요해요 (TanStack Query) |
| 전역 상태 | 여러 화면이 같이 보는 화면 쪽 값. 거실 냉장고 메모 같은 것 (Zustand) |
| 캐시 | 한 번 받아 온 데이터를 잠시 보관해 두고 다시 쓰는 것. 같은 요청을 줄여요 |
| prop drilling | 값을 쓰지도 않는 중간 컴포넌트들을 거쳐 아래로 계속 넘겨주는 것 |
| 사용량 제한 | 한 사람이 하루에 AI를 부를 수 있는 횟수 · 양의 상한. 비용을 지키려고 둬요 |
