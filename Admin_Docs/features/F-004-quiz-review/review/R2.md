## 지적 (있을 때)
- [주의] [추정] AI를 기다리는 최대 180초 동안 DB 연결을 잡고 있을 수 있다. `prepare_generation`은 `_claim_note`에서 커밋한 뒤에 `build_messages(note, chunks)`를 부른다. 세션이 기본값(`expire_on_commit=True`)이면 커밋 뒤 `note.title` · 조각 값을 읽을 때 SELECT가 다시 나가 새 트랜잭션이 연결을 가져가고, AI 호출이 끝나 `save_generation`이 커밋할 때까지 놓지 않는다. 동시 요청이 풀 크기만큼 쌓이면 다른 API도 연결을 못 받는다. — backend/app/services/quiz_generation.py:325-331 `prepare_generation`, backend/app/api/quizzes.py:126 — quiz_generation.py · quizzes.py 전체, scripts/quiz_eval.py:75. app/db/session.py는 바뀐 파일 밖이라 열지 않음 — session.py의 `expire_on_commit` 값과 풀 크기를 확인하면 확실해진다. 고치는 방법: 필요한 값을 커밋 전에 계산해 GenerationPlan에 평범한 값으로 담거나, AI를 부르기 직전에 연결을 돌려준다.
