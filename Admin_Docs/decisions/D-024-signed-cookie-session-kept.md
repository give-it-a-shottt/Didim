# D-024 로그인 세션은 서명 쿠키 그대로 — 서버에서 세션을 무효로 만들지 않는다

## 한눈에 보기 (코드 몰라도 OK)
상태: [통과] 사용자가 골랐어요(2026-11-13, Q-017).
무엇을: 로그인 상태는 지금처럼 서버가 서명한 쿠키(만료 7일)로 확인하고, 서버에 세션 목록을 두지 않아요. 로그아웃은 쿠키를 지우는 것뿐이라, 쿠키가 새어 나가면 만료 전까지 쓸 수 있어요.
왜: 혼자 쓰는 포트폴리오라 위험이 작아서요. 한계와 고치는 방법은 면접 답으로 준비해요.
