# D-014 LLM은 K-EXAONE 2.5를 메인으로 쓰고, 갈아 끼울 수 있게 만든다

## 한눈에 보기 (코드 몰라도 OK)
상태: [통과] 사용자가 골랐어요(2026-11-09).
무엇을: 퀴즈 · 카드 후보 · 자소서를 만드는 AI는 LG의 K-EXAONE 2.5 API를 써요. 대신 AI를 부르는 곳을 한 군데(인터페이스)로 모아서, 설정 하나로 가짜 AI(mock) · EXAONE · 내 컴퓨터의 오픈소스 모델(local)을 바꿔 끼울 수 있게 해요. 콘센트 모양을 하나로 정해 두면 어떤 가전이든 꽂을 수 있는 것과 같아요.
왜 (사용자 확인): 공개된 API라 쓸 수만 있으면 K-EXAONE 2.5로 프로젝트를 완성해 보고 싶다. 라마는 한글에 약하다. 바뀌면 내 컴퓨터에 오픈소스 모델을 받아서 연결한다. 내 정보는 학습에 쓰여도 상관없고, 타인 정보만 주의한다.

## 개발자 상세

### 상황
- Q-001(mock ↔ real 구조), Q-002(어떤 LLM · 임베딩) 중 LLM 부분을 정해야 했다.
- LG AI연구원이 2026-11-09 K-EXAONE 2.5 API를 무료 공개했다. OpenAI 호환 `POST https://api.exaone.ai/v1/chat/completions`, 모델 `k-exaone_v2.5`, 최대 문맥 524,288 토큰, 텍스트 전용, 항상 추론 후 답변(`reasoning_effort` low/high/max, 추론은 `message.reasoning_content`, 답은 `message.content`, 답 앞에 "\n\n"이 붙을 수 있음).

### 결정
- 메인 모델: K-EXAONE 2.5 API. 키는 `backend/.env`의 `EXAONE_API_KEY`(서버에서만, 커밋 · 문서 · 화면 쪽 금지).
- 구조: `LLM_PROVIDER = mock | exaone | local` 한 인터페이스. 셋 다 OpenAI 호환 형식이라 local은 주소(base_url)와 모델 이름만 바꾼다(Ollama · LM Studio의 작은 EXAONE 공개 모델 또는 gpt-oss).
- 개발 · 테스트 기본값은 mock(키 없이 동작, 테스트가 외부 API에 의존하지 않게).
- 응답은 정해진 JSON 스키마로 서버에서 검사하고, 틀리면 재시도 · 실패 처리(원칙 3). 구조화 출력 기능이 문서에 없어서 검사는 우리 쪽에서 한다.
- 사용량 한도 초과는 429로 오므로 원칙 4(비용 상한 · 부분 결과 보존)와 같은 경로로 처리한다.
- 임베딩은 EXAONE API에 없다 → Q-002에서 따로 정한다(F-003 전).

### 약관 · 데이터 (2026-11-09 확인)
- 비상업적 이용만 허용, "제3자가 AI 모델을 호출하도록 할 수 없음"(이용약관 제2조). 혼자 쓰는 개발 · 포트폴리오 · 평가는 괜찮아 보이나, 다른 사람이 가입해 쓰는 서비스(D-004)로 공개하기 전에 다시 확인한다(Q-019).
  - Q-019 답(사용자 확인, 2026-11-12): 공개 배포 계획 없음 — 포트폴리오용으로 본인만 사용. 면접관 시연 방식(영상 · 미리 만든 결과 · 직접 시연)은 Q-012 배포를 정할 때 함께 정한다.
- 입력값 · 결과물은 학습에 쓰일 수 있다(제2조 3항). 개인정보처리방침상 "My profile > 동의 및 알림 관리"에서 거부할 수 있다고 하나, 2026-11-09 화면 메뉴에는 해당 항목이 보이지 않았다. 사용자는 본인 정보는 학습에 쓰여도 괜찮다고 정했다.
- 타인의 개인정보는 입력 금지(제7조) → 노트의 팀원 실명 등은 보내기 전에 주의한다.
- 모델 변경 · 종료 · 유료 전환 가능(제9조) → 교체 가능한 구조로 대비.
