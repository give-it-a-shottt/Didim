# 디딤 (Didim)

**내 공부 기록에서만 쓰는, 문장마다 근거가 달린 자소서.**

디딤은 공부 기록(마크다운 · 노션)을 퀴즈로 복습하게 하고, 그 기록에서 경험 카드를 뽑아 공고에 맞는 자소서 초안과 면접 연습까지 이어 주는 서비스예요. AI가 쓴 문장에는 어느 카드의 어느 칸에서 왔는지 근거를 붙이고, 기록에 없는 문장에는 밑줄을 그어요.

- 평가 리포트: `/report` (로그인 없이)
- 샘플 체험: `/demo` (로그인 없이, 가상 지원자 기록으로 둘러보기)

## 왜 만들었나

공부 기록은 계속 쌓이는데, 복습도 지원서도 매번 처음부터 다시 했어요. 기록을 다시 읽지 않으니 배운 것이 남지 않고, 자소서를 쓸 때는 "그때 뭘 했더라"를 기억에 기대어 다시 찾았어요.

AI에게 자소서를 맡기면 빨리 쓸 수는 있어요. 하지만 그럴듯한 문장 사이에 내가 하지 않은 일과 내지 않은 성과가 섞여 들어와요. 면접에서 그 문장을 물어보면 답할 수 없어요. 그래서 디딤은 **AI가 지어낸 부분을 잡아내는 것**을 가장 중요한 설계 목표로 두었고, 그 설계가 실제로 얼마나 잡아내는지를 아래 평가 수치로 보여 줘요.

## 쓰는 법

1. **기록 가져오기** — 마크다운 파일을 올리거나 노션을 연결해 공부 기록을 가져와요. 가져온 기록은 키워드로 검색할 수 있어요.
2. **퀴즈로 복습** — 노트에서 객관식 · OX 문제를 만들어요. 문제마다 원문 인용이 붙고, 인용이 노트에 글자 그대로 없으면 그 문제는 버려요. 오늘 복습할 문제와 오답노트가 따로 모여요.
3. **경험 카드** — 기록에서 경험 후보를 찾아 상황 · 과제 · 행동 · 결과 칸으로 정리해요. 칸마다 원문 인용이 있어야 채워지고, 기록에 없는 칸은 빈칸으로 남겨요.
4. **공고 분석** — 공고를 붙여 넣으면 요구 역량을 뽑고 내 카드와 맞춰 봐요. 근거 카드가 없는 역량은 기록 검색으로 이어져요. 공고 사이트를 자동으로 긁어 오지 않아요.
5. **근거 달린 자소서** — 문항별 초안의 문장마다 근거(카드 · 칸 · 인용)를 붙여요. 근거가 없는 문장에는 '근거 없음', 카드에 없는 숫자 · 낱말이나 결과 기록이 없는 성과 표현에는 '확인 필요'를 띄우고, 제출하기 전에 한 번 더 확인해요.
6. **면접 연습** — 경험 카드의 칸마다 꼬리 질문을 만들고, 인용이 카드에 글자 그대로 없는 질문은 버려요. 지원한 공고의 면접 연습 탭에는 그 공고에 맞는 카드의 질문이 모이고, 질문마다 답을 메모해 둘 수 있어요.

## 설계에서 지킨 것

- **근거 우선** — AI가 만든 퀴즈 · 카드 후보 · 문장 · 면접 질문에는 출처(노트 · 카드와 위치)를 함께 저장하고 화면에 보여 줘요. 경험 카드에는 AI가 지어낸 내용을 저장하지 않아요.
- **AI 출력은 검증한다** — AI 응답은 정해진 형식으로 받고, 인용이 원문에 글자 그대로 있는지 검사해요. 형식이 틀리면 다시 시도하고, 그래도 안 되면 실패로 처리해요.
- **사용자 데이터 분리** — 모든 조회와 검색에 사용자 조건을 걸어요. 다른 사람의 기록이 검색되면 버그로 봐요.
- **비용 상한** — 사용자별로 하루 AI 호출 수를 제한하고, AI 작업은 한 번에 하나만 돌려요.
- **평가 가능하게** — 정답을 미리 심어 둔 가상 데이터로 기능마다 수치를 재고, 그 결과를 리포트와 아래 표로 공개해요.

### 다시 재기

```bash
cd backend
uv run --env-file .env python -m scripts.eval_all nvidia --pause 3   # 퀴즈 · 카드 · 매칭 · 자소서 · 면접
uv run python -m scripts.eval_all --rescore eval/summary/run-<시각>.json   # 사람 판정을 적은 뒤
uv run python -m scripts.eval_all --readme                                 # 이 표를 최근 회차로
```

## 기술 스택

- 화면: Next.js 16(App Router · 서버 컴포넌트) · TypeScript · Tailwind CSS 4 · TanStack Query · Playwright
- 서버: Python 3.13 · FastAPI · SQLAlchemy · Alembic · uv · pytest
- DB: PostgreSQL(기록 검색은 pg_trgm 키워드 검색)
- AI: OpenAI 호환 API(메인 NVIDIA Nemotron, EXAONE은 비교용) — 가짜 응답(mock)으로도 돌아가요

## 실행

비밀값은 각 폴더의 `.env.example`을 보고 `.env`(커밋 안 함)에 넣어요.

```bash
# DB — Docker Desktop을 켠 뒤, 레포 루트에서
docker compose up -d db

# 서버 (터미널 1)
cd backend
uv sync
uv run --env-file .env alembic upgrade head
uv run uvicorn app.main:app --reload --port 8000 --env-file .env
uv run pytest

# 화면 (터미널 2)
cd frontend
npm install
npm run dev
npm run test:e2e         # Playwright (가짜 백엔드로 실행)
```

설계 결정 · 기능별 기록 · 리뷰 결과는 [Admin_Docs/START_HERE.md](Admin_Docs/START_HERE.md)에서 시작해요.
