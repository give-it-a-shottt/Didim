# F-009 면접 연습

언제: 6주차(F-008 자소서와 같은 주, 사용자 확인 2026-11-13 — Q-005 닫힘)
무엇을: 경험 카드에서만 질문을 만들고, 지원 상세의 면접 연습 탭은 매칭된 카드 질문을 모아 보여 줘요. 내 답은 메모로
왜: 자소서에 쓴 내 경험을 깊게 묻는 면접에 대비해, 내 카드에서 나올 질문으로 답을 연습하려고요.

## 설계 의도 (사용자 확인 — 코드 작성 전에 채움, 문장 정리사 사용)
- 이 기능이 해결하는 문제: 면접에서는 자소서에 쓴 내 경험을 깊게 물어보는데, 어떤 질문이 나올지 스스로 떠올리기 어렵다. 내 경험 카드에서만 예상 질문을 만들고, 지원한 공고에 맞는 카드의 질문을 모아 답을 연습하게 한다. (사용자 확인, 2026-11-13)
- 완료 기준(무엇이 되면 끝인지): (사용자 확인, 2026-11-13)
  1. 카드 상세에서 [면접 질문 만들기]를 누르면 그 카드의 칸 글만 AI에 보내 질문을 만든다. 질문마다 근거 칸 · 인용이 붙고, 인용이 카드에 글자 그대로 없으면 버린다.
  2. 지원 상세 [면접 연습] 탭에 그 공고에 매칭된 카드의 질문을 모아 보여 주고(중복 제거), 질문마다 어느 카드 · 역량에서 왔는지 보인다. 질문 없는 카드는 카드 상세로 잇는다.
  3. 질문마다 내 답을 메모로 저장한다. 같은 질문은 다른 공고에서도 같은 메모를 보고, 답한 질문 수를 보여 준다.
  4. 평가: 가상 카드로 '카드에 없는 내용을 전제로 한 질문 수'를 재서 남긴다.
- 정한 것 (사용자 선택, 2026-11-13): 질문은 칸별 꼬리 질문으로 카드당 3~5개(빈칸에서는 안 만듦), AI 1번. 카드당 한 번만 만들고, 카드를 고친 뒤 다시 만들기는 2차 후보. 질문 생성은 카드 상세에서만(D-006).
- 화면 · 컴포넌트 (사용자 확인, 2026-11-13): 카드 상세(CRD_01_002)에 '면접 질문' 칸 + [면접 질문 만들기], 지원 상세 [면접 연습] 탭(APL_02_004)은 매칭된 카드별 질문 · 역량 태그 · 메모 칸. 모양은 Figma 원본(D-019).
- API (사용자 확인, 2026-11-13): `POST /api/cards/{id}/interview-questions`(AI, 빈칸만 있는 카드는 409) · 카드 상세 응답에 질문 목록 · `PATCH /api/interview-questions/{id}`(메모) · `GET /api/applications/{id}/interview`(매칭된 카드별 질문, 역량 이름은 태그 — 한 카드가 역량 여러 개에 매칭돼도 한 번).
- 데이터 (사용자 확인, 2026-11-13): 버전 파일 0009 — `interview_questions`(카드 FK CASCADE · 칸 · 질문 · 근거 인용 · 위치 · 메모 · 답한 시각), `card_interview_claims`(카드 선점 — D-020 ALL_TABLES에 더함), `interview_logs`(평가 로그). 모두 user_id 조건(D-004).
