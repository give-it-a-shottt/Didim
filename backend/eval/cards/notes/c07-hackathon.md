# 교내 해커톤 회고 (24시간)

## 날씨 API 연동 담당
우리 팀은 날씨에 맞춰 옷차림을 추천하는 웹앱을 만들었다. 나는 기상청 단기예보 API를 붙여 화면에 기온과 강수 확률을 보여 주는 일을 맡았다.

예보 API가 격자 좌표(nx, ny)를 요구해서 위도와 경도를 격자로 바꾸는 변환 함수를 문서의 공식대로 옮겼다. 응답이 느릴 때를 대비해 마지막으로 받은 예보를 10분 동안 저장해 두고 그 값을 먼저 보여 줬다.

## 시연 실패 대비
발표 전날 밤 리허설에서 학교 와이파이가 끊겨 API 호출이 모두 실패했다. 본 발표에서도 같은 일이 생기면 화면이 텅 비어 버릴 상황이었다.

API 응답 몇 개를 JSON 파일로 저장해 두고, 네트워크가 안 되면 그 파일로 화면을 그리는 시연 모드를 새벽 3시까지 만들었다.

본 발표 중에 실제로 와이파이가 한 번 끊겼지만 시연 모드로 넘어가 끝까지 시연했고, 팀은 장려상을 받았다.
