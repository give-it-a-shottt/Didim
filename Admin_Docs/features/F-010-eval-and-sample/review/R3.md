## 지적
- [주의] [확실] 시드가 중간에 실패하면 샘플 계정이 반쯤 채워진 채 남고 그 상태로 샘플 체험이 열린다. 멀쩡하던 이전 샘플도 이미 지워진 뒤다. reset_sample_user가 삭제 · 생성을 곧바로 commit하고, main()은 SeedError만 잡아 다른 예외(결과 JSON KeyError, prepare_* 실패)는 traceback으로 끝나며 사용자 행은 남아 `POST /api/demo/session`이 204를 준다. 반쯤 실패를 막는 테스트도 없다. — backend/app/services/sample_seed.py seed_sample · reset_sample_user, backend/scripts/seed_sample.py main — 확인한 범위: diff 전체, 실행은 안 함 — 고치는 방법: seed_sample을 try/except로 감싸 실패하면 샘플 사용자를 지우고(→ 503 '아직 준비 안 됨') SeedError로 다시 던진다. 또는 새 계정을 완성한 뒤 교체. 중간 실패를 일으키는 테스트 1개.

"runner가 1 → 반환 1, 기존 수치 유지" 테스트.
