## 지적

Q-015 임시 처리 범위 안이라 지금 필수는 아님 — frontend/src/lib/site.ts `readSiteUrl` — 확인한 범위: 패킷 코드만, 실행 안 함 — 확실해지는 방법: `SITE_URL="foo:bar" npm run build`가 오류 없이 되는지 보기 — `url.protocol`이 "http:" · "https:"가 아니면 같은 메시지로 throw.
