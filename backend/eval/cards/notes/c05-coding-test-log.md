# 코딩테스트 준비 일지

## 하루 한 문제 습관
8월에 처음 본 코딩테스트에서 2문제 중 하나도 못 풀었다. 문제를 읽고 어디서부터 손대야 할지 모르는 상태였다.

9월 1일부터 프로그래머스 문제를 하루 한 문제씩 풀고, 못 푼 문제는 다른 사람 풀이를 본 뒤 다음 날 빈 화면에서 다시 짜 보는 규칙을 세웠다. 풀이마다 왜 이 자료구조를 골랐는지 세 줄로 적었다.

60일 동안 하루도 빠지지 않았고, 10월 말 모의 테스트에서는 3문제 중 2문제를 풀었다.

## DP 개념 정리
동적 계획법은 큰 문제를 작은 부분 문제로 나누고, 부분 문제의 답을 저장해 다시 계산하지 않는 방법이다. 점화식을 먼저 세우고, 위에서 내려오는 메모이제이션이나 아래에서 쌓아 올리는 테이블 방식으로 구현한다. 부분 문제가 겹치지 않으면 분할 정복과 같아서 저장할 필요가 없다.
