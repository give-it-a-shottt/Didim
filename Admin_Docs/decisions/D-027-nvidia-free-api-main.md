# D-027 메인 AI를 NVIDIA 무료 API로 바꾼다 (EXAONE은 예비 · 비교용)

## 한눈에 보기 (코드 몰라도 OK)
상태: [통과] 사용자가 골랐어요(2026-11-16). 키 발급 · 연결 확인 · 모델 비교 끝 — 메인 Ultra, 예비 Bolt.
무엇을: 퀴즈 · 카드 · 자소서 · 면접 질문을 만드는 AI를 NVIDIA의 무료 API(build.nvidia.com)로 바꿔요. D-014에서 만든 '콘센트'(LLM_PROVIDER)에 nvidia를 하나 더 꽂은 것이라, EXAONE · 내 컴퓨터 모델도 설정 한 줄로 다시 쓸 수 있어요. 모델은 무료 표시('Free Endpoint')가 붙은 것 중에서 .env로 골라요.
왜 (사용자 확인): 무료로 쓸 수 있는 게 중요하다. 질문이 너무 벗어나지 않으면 조금 더 깊게 묻는 모델이 괜찮다.

## 개발자 상세

### 상황
- D-014는 K-EXAONE 2.5를 메인으로 정했다. 2026-11-15 저녁에는 서버가 응답하지 않았고(LLMUnavailable), 무료 API라 언제든 바뀔 수 있다(D-014 '바꿔야 하는 조건').
- 사용자가 NVIDIA 무료 API를 메인으로 붙이기를 원했다("무료 버전이 중요해", 2026-11-16).

### NVIDIA 무료 API (2026-11-16 확인 — 공식 문서 · 2026-11-12 검증된 정리 페이지)
- `POST https://integrate.api.nvidia.com/v1/chat/completions`, OpenAI 호환, `Authorization: Bearer <키>`.
- 키: NVIDIA Developer Program 가입 + 휴대폰 인증(지원 국가) → build.nvidia.com에서 발급. 카드 등록 없음.
- 무료: 카탈로그에서 'Free Endpoint' 표시가 붙은 채팅 모델만. 모델 목록(`/v1/models`)에 있다고 무료인 것은 아니다. 새 키로 목록은 보이는데 호출은 404가 날 수 있다.
- 한도: 분당 40번 · 하루 10,000번(계정당, 모델 · 혼잡에 따라 다를 수 있음). 넘으면 429 → 원칙 4와 같은 경로.
- 데이터: 체험판 — "입력과 출력이 기록되고 제품 · 모델 개선에 쓰일 수 있다". 상용 서비스용이 아니라 체험용.

### 결정
- `LLM_PROVIDER = mock | exaone | local | nvidia`. nvidia는 OpenAI 호환 클라이언트를 그대로 쓰고 주소 · 키 · 모델만 다르다(`app/llm/settings.py`).
- 키 `NVIDIA_API_KEY`(backend/.env, 서버에서만). 모델 `NVIDIA_MODEL`은 꼭 적는다 — 무료 목록이 바뀌어도 코드는 그대로, 코드에 기본 모델을 박지 않는다(사용자 선택: .env에서 고르기 + 후보 두세 개 시험).
  - `LLM_MODEL`과 따로 둔 이유: 메인을 nvidia로 둬도 `exaone`을 넘겨 부르는 평가 · 연결 확인이 EXAONE 모델 그대로 돈다(두 모델 비교 가능).
- 모델(사용자 선택 2026-11-16): **메인 `nvidia/nemotron-3-ultra-550b-a55b`(Ultra), 예비 `nvidia/nemotron-3.5-bolt-e4b`(Bolt)** — Ultra가 느리거나 응답이 없으면 `NVIDIA_MODEL`만 바꾼다.
  - 처음 후보(DeepSeek V4.1 Flash · Gemma 4 31B · GLM 5.3 Flash · gpt-oss-20b · Step 5)는 2026-11-16 모두 timeout(무료 서버 혼잡으로 보임). 키는 정상(모델 목록 200, NVIDIA 자체 모델은 1초 안에 답). `meta/llama-3.2-11b-vision`은 2026-11-05 종료(410).
  - 짧은 한국어 JSON 요청: Bolt 2초 · Ultra 4.5초 · MiniMax M3.1 Flash 26초는 인용을 글자 그대로 복사, Nemotron 3.5 Super VL · Lightning은 인용 글자를 바꿈(근거 검사에서 버려짐).
  - 면접 질문 평가(F-009, 카드 12장, 2026-11-16): EXAONE 11/12 성공 · 카드당 73초 / Ultra 12/12 · 20초 · 저장 50 · 카드에 없는 전제 2/50 / Bolt 12/12 · 5초 · 저장 45 · 전제 0/45. 근거 검사는 셋 다 전부 통과. 전제 판정은 Claude(AI)가 사용자 위임으로 매김(사람 판정 아님). Ultra를 고른 이유는 위 '왜'(사용자 확인).
- 개발 · 테스트 기본값은 그대로 mock(D-014). EXAONE은 예비 · 비교용으로 남긴다.
- 데이터 기준은 D-014와 같다: 내 기록은 기록 · 학습에 쓰여도 괜찮고, 타인 개인정보는 보내지 않는다(원칙 6).

### 이 결정을 바꿔야 하는 조건
- 고른 모델의 무료 표시가 빠지거나 무료 정책이 끝날 때 → 다른 Free Endpoint 모델로 `NVIDIA_MODEL`만 바꾸거나 exaone · local로.
- 평가(D-005)에서 근거 검사 · 매칭 수치가 EXAONE보다 크게 나쁠 때.
