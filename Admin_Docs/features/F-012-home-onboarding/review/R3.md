## 체크 항목별 근거
- 로딩 → Suspense fallback(role=status) → 처리됨.
- 에러 · 네트워크 → home-data.ts(null · !ok · 모양 틀림 → error) + role=alert + spec(500) → 처리됨, 모양 오류 경로는 테스트 없음.
- 빈 데이터 → 세 칸 빈 문구 · 체크리스트 + spec 처음 · 기록만 → 처리 · 테스트됨.
- 입력 오류 → 입력 폼 없음 → 해당 없음.
- 응답 코드 → 401(get_current_user, test 확인), 읽기 전용 → 이상 없음.
- 트랜잭션 · DB 제약 · 외부 API → 조회만 → 해당 없음.
- 경계값 → 조건식은 맞음, 6 · 7일 증명 불충분(주의).
- 자정 근처 → korea_today 정확, 테스트 없음(제안).
- count_today_reviews 리팩터링 → 조건 · user_id 같음, 전체 테스트 통과 → 동작 같음.
- 새 테스트 유효성 → step_counts · blank_cards · only_sees_my_data는 값을 직접 단언 → 유효. 약한 곳은 마감 경계.
- 테스트 통과 → 패킷 결과(SQLite 652 · PostgreSQL 665 · Playwright 1회차 sample-demo 흔들림 1 → 2회차 통과).

확인한 범위: diff.patch, packet.md, 체크리스트, lib/backend.ts · json.ts, report-data.ts 앞부분, korea_time.py.
