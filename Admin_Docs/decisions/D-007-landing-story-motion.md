## 한눈에 보기 (코드 몰라도 OK)
상태: [통과] 사용자가 골랐어요(2026-11-07).
무엇을: 홍보용 랜딩을 만들어요. 첫 화면은 30초 안에 판단하는 채용 담당자를 위해 실제 화면과 평가 수치를 바로 보여 주고, 아래로 내리면 취준생을 위한 스토리 스크롤 모션이 이어져요. 8주차가 밀리면 "히어로 + 고정 섹션 1개"로 줄여요.
왜: 서비스의 핵심("AI가 지어낸 부분을 잡아내는 순간")을 첫 화면에서 보여 주고 싶어서요.

## 개발자 상세

### 결정
- 첫 100vh: 고정 없이 헤드라인 + CTA + 실제 화면 + 평가 수치.
- 스토리 고정 구간 200vh 이하: 완성된 AI 초안 → 근거 없는 문장에 경고 밑줄 → 원문 각주가 붙거나 빠짐. "AI가 글을 써 주는" 연출은 쓰지 않는다(시니어 S5).
- 건너뛰기 링크, prefers-reduced-motion이면 정지 화면.
- 구현은 가벼운 CSS 스크롤 연동(view-timeline) 우선. 값은 디자인 md 5장 모션 표.

### 이 결정을 바꿔야 하는 조건
- 8주차에 시간이 모자라면 먼저 이 범위를 "히어로 + 고정 섹션 1개"로 줄인다(노션 연결보다 먼저 줄임).
